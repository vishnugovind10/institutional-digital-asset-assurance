# v0.2.0

## Added

- Seven controls for privileged access, emergency upgrades, contract changes, node/RPC dependencies, finality/reorganizations, incident response and key management.
- Explainable qualitative inherent/residual risk, control-effectiveness, treatment and go-live impact fields.
- Synthetic third-party assurance register with freshness, concentration/dependency, materiality, remediation and exception details.
- Governance-objective mappings from controls to linked evidence and observed results.
- Example Crypto ETP profile using the shared evaluator, controls and evidence model.
- Console summaries for qualitative risk, lifecycle and third-party assurance.

## Boundaries

All added profile data is synthetic. Risk mapping is categorical, not a numeric score or probability. Governance mappings are illustrative and make no legal, regulatory, audit or compliance claim. Provider assurance is represented by fixture data and is not independently verified.
