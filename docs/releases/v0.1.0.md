# Institutional Digital Asset Assurance v0.1.0

This release is an executable reference implementation demonstrating:

- Institutional digital-asset control assessment across custody, smart contracts, tokenisation, blockchain, settlement, governance, operations and third parties.
- Evidence-backed assurance with explicit freshness, missing-data and state-conflict handling.
- Deterministic scenario-based risk evaluation and owner-linked remediation conditions.
- Explicit go-live decisions: `GO`, `CONDITIONAL GO`, `NO-GO` and `ABSTAIN`.
- A public, no-login assurance console with control, evidence and architecture views.

All demonstration inputs and evidence are synthetic. The project is not production security software, an audit, or a compliance product.
